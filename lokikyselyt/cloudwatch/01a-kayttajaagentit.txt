# KYSYMYS: mitkä ohjelmistot kutsuvat kuntalaisrajapintaa, ja kuinka paljon?
#
# Signaali 1/6: käyttäjäagentti välityspalvelimen lokissa. Ainoa signaali, joka
#   nimeää ohjelmiston. Kaikki muut kyselyt mittaavat käyttäytymistä.
# Lokivirta: VÄLITYSPALVELIN. appName = "evaka-proxy",
#   type = "app-requests-received". Valitse välityspalvelimen lokiryhmä.
#   userAgent ei esiinny missään muussa virrassa: API-gateway hylkää req- ja
#   res-oliot kokonaan (apigw/src/pino-cli/cli/index.ts).
# Aikaväli: 7 vuorokautta.
#
# Huomaa: statusCode on tässä virrassa MERKKIJONO ja path sisältää
#   /api-etuliitteen.
#
# Tulkinta: kyselyn A tulos on koko käyttäjäagenttijakauma. Kyselyn B tulos
#   (poista A:n kommentointi ja kommentoi B) on suora vastaus kysymykseen:
#   pyynnöt, joiden käyttäjäagentti ei väitä olevansa selain. Käytännössä
#   selaimet lähettävät aina merkkijonon, joka sisältää "Mozilla/". Tyypillisiä
#   ohjelmistoagentteja ovat python-requests, curl, okhttp, Java, axios,
#   node-fetch, Go-http-client, PostmanRuntime ja tyhjä merkkijono.
#
# Väärä positiivinen: hakukoneiden ja valvontapalveluiden robotit sekä kunnan
#   omat testi- ja kuormitusajot näkyvät ei-selainagentteina, vaikka eivät ole
#   kuntalaisen ohjelmia; ne on karsittava käsin tuloslistalta.
# Väärä negatiivinen: käyttäjäagentti on asiakkaan vapaasti asettama, joten
#   selaimeksi tekeytyvä ohjelma katoaa tästä kokonaan; lisäksi koko signaali
#   puuttuu, jos välityspalvelimen lokia ei kerätä.

# --- Kysely A: koko käyttäjäagenttijakauma ---
fields @timestamp
| filter appName = "evaka-proxy" and type = "app-requests-received"
| filter strcontains(path, "/api/citizen/") = 1
| stats count(*) as pyynnot,
        count_distinct(clientIp) as ip_osoitteita
  by userAgent
| sort pyynnot desc
| limit 200
