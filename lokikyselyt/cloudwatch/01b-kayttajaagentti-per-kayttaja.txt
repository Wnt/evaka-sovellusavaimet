# KYSYMYS: kuinka moni yksittäinen kuntalainen käyttää ei-selainohjelmistoa?
#
# Signaali 1/6: käyttäjäagentti liitettynä käyttäjätunnisteeseen.
# Lokivirta: VÄLITYSPALVELIN JA API-GATEWAY YHTÄ AIKAA. Valitse molempien
#   lokiryhmät samaan kyselyyn (Logs Insights sallii usean lokiryhmän).
#   Liitosavain on traceId, joka on sama kaikissa virroissa: nginx generoi sen
#   ($request_id) ja välittää otsakkeessa X-Request-ID, jonka API-gateway lukee
#   omaksi traceId-arvokseen.
# Aikaväli: 1-7 vuorokautta. Kysely lukee kaksi riviä jokaista pyyntöä kohti,
#   joten pidennä varovasti.
#
# LIITOS: Logs Insights ei osaa join-operaatiota. Tämä kysely kiertää sen
#   ryhmittelemällä traceId:n mukaan ja poimimalla kummastakin virrasta sen
#   kentän, joka vain siinä on täytetty:
#     - userAgent on olemassa vain välityspalvelimen rivillä
#     - userIdHash on välityspalvelimen rivillä aina tyhjä merkkijono ja
#       API-gatewayn rivillä täytetty tunnistautuneilla pyynnöillä
#   sortsLast() järjestää merkkijonot aakkosjärjestykseen ja palauttaa
#   viimeisen, joten tyhjä merkkijono häviää aina oikealle tiivisteelle.
#
# Tulos on yksi rivi pyyntöä kohti: käyttäjäagentti ja käyttäjätiiviste rinnan.
# Yhteenveto agenttia kohti vaatii toisen vaiheen:
#   a) jos konsolisi hyväksyy kaksi stats-komentoa samassa kyselyssä, poista
#      tiedoston lopun kommentointi; tai
#   b) vie tulos CSV:nä ja tee pivot taulukkolaskennassa (käyttäjäagentti
#      riveille, count_distinct(userIdHash) arvoksi).
#
# Väärä positiivinen: kuntalainen voi käyttää sekä selainta että ohjelmaa;
#   yksi ei-selainrivi ei tee koko käyttäjästä ohjelmakäyttäjää, vaan osuutta
#   on katsottava suhteessa hänen kokonaispyyntömääräänsä.
# Väärä negatiivinen: tunnistautumattomat pyynnöt (userIdHash tyhjä molemmissa)
#   eivät liity kehenkään, ja selaimeksi tekeytyvä ohjelma jää näkymättä.

fields @timestamp
| filter type = "app-requests-received"
| filter appName = "evaka-proxy" or appName = "evaka-api-gw"
| filter strcontains(path, "/api/citizen/") = 1
| stats sortsLast(userAgent) as kayttajaagentti,
        sortsLast(userIdHash) as kayttaja,
        count(*) as rivit
  by traceId
| filter rivit >= 2 and kayttaja != ""
| filter strcontains(kayttajaagentti, "Mozilla/") = 0
| sort kayttajaagentti
| limit 10000
